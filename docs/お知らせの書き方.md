# 公式サイトのお知らせの書き方（なおぴ向け）

サイトの「NEWS」欄には、Googleスプレッドシート「なおぴ公式サイト お知らせ」に書いた内容が、そのまま表示されます。
スマホの「Google スプレッドシート」アプリからでも書けます。

## 書き方
1. スプレッドシートを開き、下の「お知らせ」シートを選ぶ（リンクは別で送ります）
2. いちばん下の、空いている行に書く

| 列 | 書くこと | 例 |
|---|---|---|
| 日付 | `2026/12/03` の形で | 2026/12/03 |
| タイトル | 一言で | 誕生日配信やります |
| 本文 | くわしい内容。改行もOK（なくてもOK） | 12月3日 21時からTwitchで！ |
| リンク | 関係するページのURL（なくてもOK） | https://www.twitch.tv/naopi123 |
| 表示 | **チェックを付ける**とサイトに出る | ☑ |

迷ったら、見出しのセルにマウスを乗せるか、タップしてください。書き方のメモが出ます。
「使い方」シートにも同じ手順が書いてあります。

## 知っておくこと
- サイトに出るのは、**チェックが付いた行のうち、新しい順に5件**です。
- 消したいお知らせは、**チェックを外すだけ**でOKです。外した行は灰色になります。
- 書いてからサイトに出るまで、最大5分ほどかかります。
- 「お知らせ」シートの1行目（見出し）と、シートの名前・順番は変えないでください。
- 日付の形が違う行（例：「あした」）は表示されません。

## 今週の予定の書き方（「今週の予定」シート）
サイトの「今週の予定」欄には、同じスプレッドシートの「今週の予定」シートの内容が、月〜日のカードで表示されます。
**今週と来週の2週間分**を書いておけます（白い行＝今週、水色の行＝来週）。

| 列 | 書くこと | 例 |
|---|---|---|
| 日付・曜日 | 自動で入ります（**消さない・変えない**） | 2026/11/30・月 |
| 時間 | 始まる時間。未定なら空欄でOK（「時間未定」と出ます） | 20:00〜 |
| 内容 | 配信の内容。空欄か「おやすみ」で 🌙おやすみ 表示 | VALORANTランク |
| ひとこと | カードの下に小さく出る一言（なくてOK） | コラボあり！ |

- サイトに出るのは「今週」の分だけです。**日曜23:59が過ぎる（月曜0:00）と、自動で「来週」の分に切り替わります。**
- 月曜の0時台に、来週の行が今週の行へ自動で上がり、来週の行は空になります。次の週の予定はそこに書いてください。
- 今日のカードには「🌷 TODAY」が出ます。1週間ぜんぶ空欄だと、サイトの「今週の予定」欄ごと隠れます。
- 書いてからサイトに出るまで、最大で数分かかります。
- 「今週の予定」シートの1行目（見出し）、日付・曜日の列、シートの名前は変えないでください。

### 管理者向け（しくみ）
- 自動の切り替えは、スプレッドシートの「拡張機能 → Apps Script」（プロジェクト名「無題のプロジェクト」）の `rollWeek` が、毎週月曜0時台に動きます。コードは scripts/sheet-week.gs。
- サイトは日付を見て今週の行を選ぶので、rollWeek が遅れても表示は月曜0:00ちょうどに切り替わります。
- シートを作り直すときは `setup` を実行（書いてある予定は残ります）。

## 自動で出るもの（何もしなくてOK）
- Twitch の「配信中」マーク・次の配信予定・最近の配信 → Twitch の「スケジュール」に予定を入れておくと出ます
- YouTube の最新動画
