# 公式サイトのお知らせの書き方（なおぴ向け）

サイトの「NEWS」欄には、Googleスプレッドシートに書いた内容がそのまま表示されます。
スマホの「Google スプレッドシート」アプリからでも書けます。

## 書き方
1. お知らせ用のスプレッドシートを開く（リンクは別で送ります）
2. 2行目に、新しい行を1つ追加する
3. 下の5つの列を埋める

| 列 | 書くこと | 例 |
|---|---|---|
| 日付 | `2026/12/03` の形で | 2026/12/03 |
| タイトル | 一言で | 誕生日配信やります |
| 本文 | 自由に（改行もOK） | 12月3日 21時からTwitchで！ |
| リンク | あれば `https://` から（なくてもOK） | https://www.twitch.tv/naopi123 |
| 表示 | `○` を入れるとサイトに出る | ○ |

[スクリーンショット：スマホアプリで1行追加しているところ]

## 知っておくこと
- サイトに出るのは、**表示が `○` の行の、新しい順に5件**です。「まる」で変換して出る `○` `〇` `◯` のどれでも大丈夫です。
- 消したいお知らせは、行を消すか、表示の `○` を消すだけでOKです。
- 書いてから数分で反映されます（Googleの都合で最大5分ほどかかることがあります）。
- 1行目（日付・タイトル…の見出し）は消さないでください。
- 日付の形がちがう行（例：「あした」）は表示されません。

## 自動で出るもの（何もしなくてOK）
- Twitch の「配信中」マーク・次の配信予定・最近の配信 → Twitch の「スケジュール」に予定を入れておくと出ます
- YouTube の最新動画
