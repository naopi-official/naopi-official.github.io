# ファンアートの追加方法（なおぴ公式サイト）

作成日：2026-11-24

Googleドライブの「ファンアート」フォルダに画像を入れると、1時間以内にサイトの FAN ART 欄に載ります。

## 配信者本人がやること（毎回）

1. スマホのGoogleドライブアプリで「なおぴHP ファンアート」フォルダを開く
2. ＋ →「アップロード」でファンアートの画像を入れる
3. ファイル名を **作者名** にする（例：`もちこ.jpg`、Xの名前なら `@mochiko.jpg`）
   - ファイル名が作者名として「illust: もちこ」と表示されます
   - `IMG_1234.jpg` のような自動でついた名前のままだと、作者名は出ません
   - 同じ人の2枚目は `もちこ_2.jpg` のようにすると、作者名は「もちこ」になります
4. 1時間以内にサイトに出ます。新しく入れたものほど前に並びます（最大30枚）
5. 載せるのをやめたいときは、フォルダから画像を外します

※ 載せる前に、描いた人の許可を取ってください。

## はじめに1回だけ（サイトの管理者がやること）

### A. Googleドライブのフォルダを作る
1. Googleドライブで「なおぴHP ファンアート」フォルダを作る
2. 共有 →「一般的なアクセス」を **リンクを知っている全員（閲覧者）** にする
   - サイトに載せる絵なので、閲覧は公開で問題ありません
3. 配信者本人のGoogleアカウントを **編集者** として追加する
4. フォルダのURL `https://drive.google.com/drive/folders/〇〇〇〇` の 〇〇〇〇（フォルダID）を、サイトの担当者に伝える
   → `site/data/profile.json` の `fanartFolderId` に入れて公開します

### B. Googleの読み取り用キーを作る
1. https://console.cloud.google.com/ を開き、プロジェクトを1つ作る（例：naopi-hp）
2. 「APIとサービス」→「ライブラリ」で **Google Drive API** を有効にする
3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
4. 作ったキーの「キーを制限」で、APIの制限を **Google Drive API だけ** にする
5. キーはチャットやファイルに書かず、次のCに直接貼る

### C. GitHubにキーを登録する
1. GitHub（naopi-official）で `naopi-official.github.io` リポジトリを開く
2. Settings → Secrets and variables → Actions → New repository secret
3. Name：`GDRIVE_API_KEY`、Secret：Bで作ったキー → Add secret

A〜Cが終われば、次の毎時の更新から取り込みが始まります（Actions → feeds-and-deploy → Run workflow で今すぐ動かすこともできます）。

## うまく出ないとき
- フォルダの共有が「制限付き」のままだと取り込めません（A-2）
- Actions のログの「Googleドライブのファンアートを取得」に理由が出ます
- 取り込みに失敗しても、サイトのほかの部分はいつもどおり更新されます
