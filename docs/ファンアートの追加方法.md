# ファンアートの追加方法（なおぴ公式サイト）

作成日：2026-11-24

Googleドライブの「ファンアート」フォルダに画像を入れると、1時間以内にサイトの FAN ART 欄に載ります。

## 配信者本人がやること（毎回）

1. スマホのGoogleドライブアプリで「なおぴHP ファンアート」フォルダを開く
2. ＋ →「アップロード」でファンアートの画像を入れる
3. ファイル名を **作者名** にする（例：`もちこ.jpg`、Xの名前なら `@mochiko.jpg`）
   - ファイル名が作者名として「illust: もちこ」と表示されます
   - `IMG_1234.jpg` のような自動でついた名前のままだと、作者名は出ません
   - 同じ人の2枚目は `もちこ_2.jpg` のようにすると、作者名は「もちこ」になります
4. 1時間以内にサイトに出ます。新しく入れたものほど前に並びます（最大30枚）
5. 載せるのをやめたいときは、フォルダから画像を外します

※ 載せる前に、描いた人の許可を取ってください。

## はじめに1回だけ（サイトの管理者がやること・スマホで）

### A. Googleドライブのフォルダを作る（ドライブアプリ）
1. 右下の「＋」→「フォルダ」→ 名前 `なおぴHP ファンアート` →「作成」
2. フォルダの「︙」→「共有」（なければ「アクセス管理」）→「一般的なアクセス」を **リンクを知っている全員（閲覧者）** にする
3. 同じ画面で配信者本人のGmailアドレスを入れ、役割を **編集者** にして送信
4. フォルダの「︙」→「リンクをコピー」→ サイトの担当者に送る
   → `site/data/profile.json` の `fanartFolderId` に入れて公開します

### B. Googleの読み取り用キーを作る（スマホのブラウザ。崩れるときは「PC版サイト」に切り替え）
1. https://console.cloud.google.com/projectcreate でプロジェクト `naopi-hp` を作る
2. https://console.cloud.google.com/apis/library/drive.googleapis.com で「有効にする」
3. https://console.cloud.google.com/apis/credentials →「＋ 認証情報を作成」→「APIキー」
4. 「APIの制限」→「キーを制限」→ **Google Drive API だけ** にチェックして作成
5. キー（AIza で始まる）をコピー。チャットやメモには貼らず、次のCに直接貼る

### C. GitHubにキーを登録する（スマホのブラウザ。GitHubアプリでは不可）
1. https://github.com/naopi-official/naopi-official.github.io/settings/secrets/actions/new を開く（naopi-official でログイン）
2. Name：`GDRIVE_API_KEY`、Secret：Bのキー →「Add secret」

A〜Cが終われば、次の毎時の更新から取り込みが始まります（Actions → feeds-and-deploy → Run workflow で今すぐ動かすこともできます）。

## うまく出ないとき
- フォルダの共有が「制限付き」のままだと取り込めません（A-2）
- Actions のログの「Googleドライブのファンアートを取得」に理由が出ます
- 取り込みに失敗しても、サイトのほかの部分はいつもどおり更新されます
